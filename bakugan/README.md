# Pyrax — personal Bakugan companion

Talk with **Pyrax**, your Pyrus-attribute Bakugan partner. Loyal, fiery, and built to chat.

## Talk locally (playground)

```bash
cd bakugan
npm install
npx @grok/agent-sdk login
npx @grok/agent-sdk serve --dir . --mode single --dev
```

Open [http://127.0.0.1:3000/playground](http://127.0.0.1:3000/playground) and say hi.

## Visual companion

See `../companion` for the animated sphere + chat UI you can open in a browser.
