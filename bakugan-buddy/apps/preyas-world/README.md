# Preyas World — Desktop Preyas (slice D1)

A tiny Godot 4.7 desktop pet: Preyas as the 24x24 pixel sprite (at 4x = 96 px)
in a borderless, transparent, always-on-top strip along the bottom of the
usable screen, above the Dock. Pure GDScript, no addons, no third-party code.

## What he does

- Walks slowly along the strip, pauses sometimes, turns at the edges.
- Swaps his two breathing frames about every 500 ms.
- Drag him; he falls back down and keeps walking when you drop him.
- Every 60 s he GETs the brain's mood (`GET http://127.0.0.1:8788/v1/mood`,
  read-only) and shows the matching pose; brain off -> neutral.
- Between 23:00 and 07:00 he sleeps (sleepy pose = sad pose, no walking).
- Single click opens the chat (http://localhost:8081). Right-click shows a
  small menu: Hide for 1 hour / Quit.
- Clicks pass through everywhere except on Preyas (DisplayServer mouse
  passthrough, updated as he moves). CPU stays low: max_fps 20 and
  low-processor mode.

## Art

`data/preyas-sprite.json` is generated by `scripts/export-sprite.mjs` from the
mobile app's own sources (`apps/mobile/src/bits/preyasSprite.ts` +
`bitPalette.ts`). No new art is drawn and no other art is copied.

Regenerate after art changes:

```
node bakugan-buddy/apps/preyas-world/scripts/export-sprite.mjs
```

## Start

```
bash bakugan-buddy/launcher/preyas-world.sh
```

Quit from the right-click menu.

## Tests

From the repo root:

```
npm run test:preyas-world           # Node sprite-export test + headless Godot checks
GODOT_BIN=/path/to/godot npm run test:preyas-world:gdscript  # Godot checks only
```

CI runs both halves: the Node sprite-export test and the GDScript check suite
under headless Godot (the Linux Godot 4.7.2 build is downloaded in the step).

The logic lives in plain scripts with no node dependencies (`scripts/walker.gd`,
`scripts/mood.gd`, `scripts/sprite_data.gd`, `scripts/texture_builder.gd`) so
it is testable headless and reusable for the future Bakugan world.

## Debug helpers (optional)

- `PREYAS_MOOD_URL=http://127.0.0.1:PORT/mood` — point the mood poll at a mock
  instead of the real brain (the pet still only GETs).
- `PREYAS_DEBUG_SHOT=1` — print window/sprite geometry once and save the
  window's own pixels to `user://debug-shot.png` after six seconds.
